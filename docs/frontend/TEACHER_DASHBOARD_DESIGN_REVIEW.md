### 決策 2: Glassmorphism 視覺效果

#### 設計概念
玻璃擬態效果，營造現代、輕盈的視覺感受

#### 應用場景
```
✓ 統計卡片背景
✓ 懸浮彈窗/Modal
✓ 導航列（可選）
✗ 不適用於大面積內容區
```

#### 範例效果
```css
.glass-card {
  background: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.3);
  box-shadow: 0 8px 32px rgba(31, 38, 135, 0.15);
}
```

#### 討論問題
- ✅ **性能考量**: backdrop-filter 在低端裝置的表現？
- ✅ **瀏覽器支援**: Safari < 15.4 需要 -webkit- 前綴
- 🤔 是否提供降級方案（純色背景）？
- 🤔 應用範圍是否適當？

### 決策 3: 資料視覺化圖表

#### 提議新增圖表

**1. 進度分佈圖 (Donut Chart)**
- **位置**: Overview 首屏
- **數據**: 優秀/良好/需關注學生分佈
- **價值**: 班級整體狀況一目了然
- **優先級**: 🔥 高

**2. 學習趨勢圖 (Line Chart)**
- **位置**: Analytics View
- **數據**: 週間反思記錄、想法節點、任務數量
- **價值**: 識別學習模式、活躍時段
- **優先級**: 🔥 高

**3. 學生能力雷達圖 (Radar Chart)**
- **位置**: Individual View
- **數據**: 5 維度評分（反思/創意/任務/協作/自主）
- **價值**: 全面了解學生能力
- **優先級**: ⚠️ 中（需要評分演算法）

**4. 活動熱圖 (Heatmap)**
- **位置**: Analytics View
- **數據**: 24小時 x 7天 活動分佈
- **價值**: 了解學生學習時間模式
- **優先級**: ⚪ 低（可後期增加）

#### 討論問題
- 🤔 優先實作哪 2 個圖表？
- 🤔 雷達圖的 5 維度評分如何計算？
- 🤔 是否需要圖表互動功能（點擊鑽取）？
- 🤔 圖表色彩是否與狀態色一致？

### 決策 5: 導航按鈕優化

#### 當前問題
- 小螢幕上 6 個按鈕擁擠
- 視覺層次不明顯

#### 提議方案

**桌面版（≥1024px）**
```
[ 總覽 ] [ 所有學生 ] [ 小組 ] [ 個人 ] [ 分析 ] [ Help-Seeking ]
```
- Tab 樣式，水平排列
- 當前項目高亮（品牌綠色）

**移動版（<1024px）**
```
┌─────────────────────────┐
│ ▼ 總覽                  │
└─────────────────────────┘
```
- Dropdown 選單
- 節省空間，更易點擊

#### 討論問題
- 🤔 是否需要更激進的簡化（隱藏部分模式）？
- 🤔 移動版改用 bottom navigation？
- 🤔 是否增加快捷鍵支援（Tab 切換）？

## 📊 風險評估

### 技術風險

| 風險項目 | 影響程度 | 發生機率 | 緩解措施 |
|---------|---------|---------|---------|
| Glassmorphism 性能問題 | 中 | 中 | 提供降級方案、性能測試 |

| 跨瀏覽器相容性 | 低 | 中 | 早期測試、Polyfill |

| 風險項目 | 影響程度 | 發生機率 | 緩解措施 |
