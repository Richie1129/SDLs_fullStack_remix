# 🎯 動態反思引導功能實作

> **功能**: 根據選擇的專案階段，動態顯示該階段的反思引導問題  
> **實作日期**: 2026-02-05  
> **狀態**: ✅ 完成

---

## 📋 功能概述

為反思日誌新增「動態反思引導」功能，使用者選擇不同的專案階段後，寫作提示會自動切換為該階段的專屬引導問題，幫助學生進行更深入、更有針對性的反思。

---

## 🎨 使用者體驗流程

### 情境 1: 未選擇階段（通用模式）

```
使用者開啟「新增個人日誌」
  ↓
點擊「寫作提示」按鈕 (❓ 圖示)
  ↓
顯示通用提示：
  1. 最近完成的進度內容
  2. 完成的心得反思
  3. 下次預計完成的進度內容
  4. 是否遇到新的問題
```

### 情境 2: 選擇階段 2-2（動態模式）

```
使用者開啟「新增個人日誌」
  ↓
選擇「專案階段」→ 2-2 設計研究
  ↓
點擊「寫作提示」按鈕
  ↓
顯示階段專屬引導：
  📝 設計研究（設計&分析）階段反思引導
  
  以下問題可以幫助你更深入地反思這個階段的學習：
  
  1. 你們的研究設計是什麼？為什麼這樣設計？
  2. 預計的樣本規模是多少？如何決定的？
  3. 資料收集的方法是什麼？有什麼優缺點？
  4. 分析方法為何？為什麼選擇這個方法？
```

## 📊 各階段引導問題清單

### Stage 1: 定標

#### 1-1 分組
- 你們如何決定研究主題？過程中有哪些想法？
- 為什麼選擇這個主題？它對你們有什麼意義？
- 分組過程順利嗎？有遇到什麼困難？
- 組員之間的想法有什麼不同？如何達成共識？

#### 1-2 專題設定
- 你們如何確定研究題目和目的？
- 找到哪些相關資料或文獻？它們如何幫助你理解主題？
- 研究題目有經過修改嗎？為什麼要調整？
- 這個階段最大的收穫是什麼？

### Stage 2: 擇策

#### 2-1 文獻探討
- 你們找到了哪些重要文獻？
- 這些文獻如何幫助你們理解研究主題？
- 文獻搜尋過程中有什麼困難？如何克服？
- 從文獻中發現了什麼新的想法或方向？

#### 2-2 設計研究（設計&分析）
- 你們的研究設計是什麼？為什麼這樣設計？
- 預計的樣本規模是多少？如何決定的？
- 資料收集的方法是什麼？有什麼優缺點？
- 分析方法為何？為什麼選擇這個方法？

### Stage 3: 執行

#### 3-1 撰寫發展
- 目前撰寫進度到哪裡了？
- 撰寫過程中遇到什麼困難？
- 如何組織和呈現研究結果？
- 還需要補充哪些內容？

### Stage 4: 評估

#### 4-1 組內同儕互評
- 組員給了什麼建議？哪些建議最有幫助？
- 你對其他組員的報告有什麼看法？
- 互評過程中學到了什麼？
- 打算如何改進你們的報告？

#### 4-2 組際同儕互評
- 其他組給了什麼回饋？哪些觀點讓你印象深刻？
- 不同的觀點如何幫助你重新思考研究？
- 你覺得哪些改進想法最值得採用？
- 從其他組的報告中學到了什麼？

#### 4-3 成果發表
- 發表過程順利嗎？有什麼印象深刻的時刻？
- 觀眾或評審提出了哪些問題？你如何回應？
- 對於未來的建議是什麼？
- 整個專題下來，最大的收穫是什麼？

## 🎯 設計理念

### 為什麼這樣設計？

1. **漸進式引導**
   - 未選階段 → 通用提示（降低門檻）
   - 選擇階段 → 專屬引導（提升深度）

2. **符合認知負荷理論**
   - 一次只顯示 4 個引導問題
   - 問題具體且易於理解
   - 避免資訊過載

3. **呼應任務表單**
   - 引導問題與任務提交表單的延伸思考一致
   - 形成完整的學習循環：任務 → 提示 → 反思

## 🧪 測試場景

### 測試 1: 切換階段
1. 開啟個人日誌
2. 選擇階段 `1-1`
3. 點擊提示按鈕 → 確認顯示「分組」引導
4. 切換到階段 `2-2`
5. 再次點擊提示按鈕 → 確認顯示「設計研究」引導

### 測試 2: 清除階段
1. 選擇階段 `3-1`
2. 點擊提示按鈕 → 確認顯示「撰寫發展」引導
3. 將階段改為「不指定階段」
4. 再次點擊提示按鈕 → 確認顯示通用提示

### 測試 3: 智慧推薦
1. 設定 localStorage: `currentStage=2`, `currentSubStage=2`
2. 開啟個人日誌
3. 確認階段選擇器推薦 `2-2`（⭐）
4. 點擊提示按鈕 → 自動顯示「設計研究」引導
