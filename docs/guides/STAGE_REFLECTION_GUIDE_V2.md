## 🎯 方案 B 核心特點

### 1. 獨立元件設計
```
StageReflectionGuide.jsx
  ├─ 核心任務說明
  ├─ 反思引導問題 (4-5 個)
  ├─ 範例回答（可展開）
  └─ 實用小提示
```

### 2. 豐富的內容層次

#### 層次 1: 核心任務 🎯
```
明確說明該階段的主要目標
例如：「組成研究團隊，確定初步的研究方向和主題。」
```

#### 層次 2: 引導問題 ❓
```
4-5 個具體的反思問題
引導學生深入思考該階段的學習
```

#### 層次 3: 範例回答 📝
```
每個問題都附有實際範例
點擊「查看範例」展開
幫助學生理解如何回答
```

#### 層次 4: 小提示 💡
```
3 個實用建議
例如：「記錄團隊討論的過程比結果更重要」
```

```
   │                                │

   │     [查看範例]                  │
   │ Q2. 預計的樣本規模是多少？如何決定的？   │
   │     [查看範例]                  │
   │ ...                            │
   │                                │
   │ 💡 小提示                       │
   │ • 詳細說明研究設計的理由        │
   │ • 記錄設計過程中的考量和取捨    │
   │ • 反思設計的可行性和限制        │
   └────────────────────────────────┘
   ↓
4. 點擊「查看範例」
   ↓
5. 展開範例回答
   ┌────────────────────────────────┐

   └────────────────────────────────┘
   ↓
6. 參考範例，在下方輸入框撰寫反思
   ↓
7. 如果覺得引導太長，可以點擊收合
```

## 🛠️ 技術實作

### 元件架構

```jsx
<StageReflectionGuide stage="2-2">
  <Header>
    <Title>階段 2-2 - 設計研究反思引導</Title>
    <ExpandButton />
  </Header>
  
  <AnimatedContent isExpanded={true}>
    <CoreTask>核心任務說明</CoreTask>
    
    <ReflectionQuestions>
      {questions.map(q => (
        <Question>
          <QuestionText>{q.question}</QuestionText>
          <ExampleToggle>
            <Example>{q.example}</Example>
          </ExampleToggle>
        </Question>
      ))}
    </ReflectionQuestions>
    
    <Tips>
      {tips.map(tip => <Tip>{tip}</Tip>)}
    </Tips>
  </AnimatedContent>
</StageReflectionGuide>
```

### 動畫效果

```javascript
// 1. 元件淡入
initial={{ opacity: 0, y: -10 }}

// 2. 展開/收合動畫
<AnimatePresence>
  {isExpanded && (
    <motion.div
      initial={{ height: 0, opacity: 0 }}
      animate={{ height: 'auto', opacity: 1 }}
      exit={{ height: 0, opacity: 0 }}
    />
  )}
</AnimatePresence>

{showExamples[index] && (

  />
```

## 📚 內容範例展示

### 階段 1-1 分組

#### 🎯 核心任務
組成研究團隊，確定初步的研究方向和主題。

#### ❓ 反思引導問題

**Q1. 你們如何決定研究主題？過程中有哪些想法？**  
📝 範例：「我們先各自提出 3 個感興趣的主題，然後投票選出最多人有興趣的方向，最後討論確定了『高中生使用社群媒體對睡眠的影響』這個主題。」

**Q2. 為什麼選擇這個主題？它對你們有什麼意義？**  
📝 範例：「因為我們都有晚睡滑手機的習慣，想了解這對睡眠品質的影響，希望能找到改善的方法。」

**Q3. 分組過程順利嗎？有遇到什麼困難？**  
📝 範例：「大家一開始意見很分歧，有人想研究環保、有人想研究科技，後來決定找共同點，發現大家都關心健康議題。」

**Q4. 組員之間的想法有什麼不同？如何達成共識？**  
📝 範例：「A 同學想做實驗，B 同學想做問卷，最後決定用問卷調查因為更可行，但會在問卷中加入實驗性的問題。」

#### 💡 小提示
- 記錄團隊討論的過程比結果更重要
- 不同意見是正常的，重點是如何溝通
- 可以提到每個組員的想法和貢獻

---

### 階段 4-3 成果發表

#### 🎯 核心任務
正式發表研究成果，回應提問並反思整個歷程。

#### ❓ 反思引導問題

**Q1. 發表過程順利嗎？有什麼印象深刻的時刻？**  
📝 範例：「報告時很緊張，但看到觀眾點頭回應時很有成就感。Q&A 環節比預期順利。」

**Q2. 觀眾或評審提出了哪些問題？你如何回應？**  
📝 範例：「評審問為何只用問卷不做實驗？我解釋了時間和資源的限制，並說明問卷的優勢。」

**Q3. 對於未來的建議是什麼？**  
📝 範例：「可以擴大樣本到其他學校，或加入實驗組做對照研究。」

**Q4. 整個專題下來，最大的收穫是什麼？**  
📝 範例：「學會完整的研究流程，培養批判思考能力，也學會團隊合作解決問題。」

#### 💡 小提示
- 記錄發表的經驗和感受
- 反思整個研究歷程的學習
- 思考未來可以改進的方向
