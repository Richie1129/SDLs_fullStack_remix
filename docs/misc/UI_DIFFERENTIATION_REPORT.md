### 2. 智能橫幅提示（方案 3）

**檔案**: `SmartReflectionBanner.jsx`  
**位置**: `/sdl-frontend-main/src/pages/reflection/components/`

#### 觸發邏輯

**情境 1: 建議嘗試 5Rs**
- 條件: 最近 5 筆日誌中有 3 筆以上是傳統日誌
- 行動: 顯示紫色橫幅，建議嘗試深度反思
- 冷卻: 24 小時內不重複顯示

**情境 2: 階段里程碑**
- 條件: 進入新專案階段
- 行動: 顯示金色橫幅，建議進行階段總結
- 追蹤: localStorage 記錄最後階段

**情境 3: 鼓勵記錄**
- 條件: 7 天以上未記錄任何反思
- 行動: 顯示綠色橫幅，鼓勵快速記錄
- 計算: 自動計算距離上次記錄的天數

#### 橫幅樣式
```javascript
綠色橫幅（鼓勵記錄）:
- 背景: 綠色到青綠色漸層
- 圖標: 💡
- 按鈕: 綠色背景

紫色橫幅（建議 5Rs）:
- 背景: 紫色到粉色漸層
- 圖標: 🎓
- 按鈕: 紫粉漸層背景

金色橫幅（階段里程碑）:
- 背景: 琥珀色到黃色漸層
- 圖標: 🎯
- 按鈕: 琥珀色背景
```

#### 行為特性
- ✅ 淡入淡出動畫（Framer Motion）
- ✅ 可關閉設計（右上角 X 按鈕）
- ✅ 行動按鈕 + "稍後再說" 按鈕
- ✅ 24 小時冷卻機制
- ✅ 裝飾性圓形背景元素

#### 視覺差異

border-left: 4px solid #5BA491        // 左側綠色粗邊框

**5Rs 反思卡片**:
```css
border-left: 4px solid purple-400     // 左側紫色粗邊框
background: 紫粉漸層 50% 透明度        // 漸層背景
title-color: 紫粉漸層文字              // 漸層標題
badge: 紫粉漸層背景 + AI 圖標           // "5Rs 反思" + AI 標籤
button: 紫粉漸層背景                   // 編輯/查看按鈕
```

#### 動態樣式函式
```javascript
const getCardStyles = () => {
  if (is5Rs) {
    return {
      borderClass: 'border-l-4 border-purple-400',
      bgClass: 'bg-gradient-to-br from-purple-50/50 to-pink-50/50',
      titleClass: 'bg-gradient-to-r from-purple-600 to-pink-600 bg-clip-text text-transparent',
      badgeClass: 'bg-gradient-to-r from-purple-500 to-pink-500 text-white',
      buttonClass: 'bg-gradient-to-r from-purple-500 to-pink-500 hover:from-purple-600 hover:to-pink-600 text-white',
    };
  }
  return {
    borderClass: 'border-l-4 border-[#5BA491]',
    bgClass: 'bg-white',
    titleClass: 'text-[#5BA491]',
    badgeClass: 'bg-[#5BA491]/10 text-[#5BA491]',
    buttonClass: 'bg-[#5BA491] hover:bg-[#5BA491]/90 text-white',
  };
};
```

## 🎨 設計系統一致性

### 色彩系統

**傳統日誌（綠色主題）**:
- 主色: `#5BA491` (customgreen)
- Hover: `#5BA491/90` (90% 透明度)
- 輔助: `#4A9680` (深綠色)

**5Rs 反思（紫粉主題）**:
- 主色: `purple-500` to `pink-500` (漸層)
- Hover: `purple-600` to `pink-600` (深化漸層)
- 輔助: `purple-400`, `pink-400`

**中性色**:
- 背景: `gray-50`, `white`
- 文字: `gray-600`, `gray-700`, `gray-800`
- 邊框: `gray-200`, `gray-100`

### 間距系統（符合 DESIGN_SYSTEM.md）

```javascript
p-component-sm    // 12px - 小元件內邊距
p-component-md    // 20px - 中型元件
gap-stack-xs      // 8px - 最小間距
gap-stack-sm      // 16px - 小間距
gap-stack-base    // 20px - 基礎間距
gap-stack-md      // 24px - 中等間距
```

### 字體系統

```javascript
text-caption      // 12px - 標籤、說明

text-body         // 16px - 標準正文
text-body-lg      // 18px - 大型正文
text-h5           // 20px - 小標題
text-h4           // 24px - 中標題
text-h3           // 28px - 大標題
```

### 動畫系統

```javascript
duration-fast     // 150ms - Hover 微互動

```

## 📱 響應式設計

### 斷點策略

```css
/* 手機 (< 640px) */
- 單列佈局
- 較小字體 (text-body-sm)
- 緊湊間距 (p-component-base)

/* 平板 (≥ 768px, md) */
- 雙列卡片（雙卡片選擇器）
- 標準字體 (text-body)
- 標準間距 (p-component-md)

/* 桌面 (≥ 1024px, lg) */
- 雙列主佈局（個人日誌 | 小組日誌）
- 大字體 (text-h2, text-h3)
- 寬鬆間距 (p-component-md-lg)
```

### 按鈕適配

```javascript
手機:
- 全寬按鈕 (w-full on flex-col)
- 小圖標 (w-4 h-4)
- 緊湊內邊距 (px-3 py-2)

桌面:
- 自適應寬度 (w-auto)
- 標準圖標 (w-5 h-5)
- 標準內邊距 (px-4 py-2.5)
```
