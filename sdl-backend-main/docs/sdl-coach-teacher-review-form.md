# SDL Coach 計畫 — 教師審查表

> **受訪對象**：高中「自然科學探究與實作」任課教師
> **預計填寫時間**：約 15 分鐘
> **目的**：請教師判斷「SDL 自主學習助手」目前的設計與範例，是否符合高中探究與實作課程的教學現場需求。
> **填寫方式**：在每題的方框打勾並寫 1–3 句備註即可，不需要長篇回答。

## 開場：20 秒背景說明

我們在開發一個「自主學習助手」，讓學生在做探究專案時，可以在平台內向 LLM 提問，LLM 會看到學生的**當前階段、看板任務、已繳交內容、想法牆**，再用反問式引導幫學生想下一步。

系統把學習流程切成 **5 個階段**：

1. **定標**（對應課綱：發現問題）
2. **擇策**（對應課綱：規劃與研究）
3. **監評**（對應課綱：論證與建模）
4. **調節**（對應課綱：表達與分享）
5. **學習歷程**（對應課綱：評價與省思）

以下請協助審查三個核心問題。

## 問題 2：Before / After 範例看起來像真實高一生嗎？

以下是一個計畫裡設計的範例場景。

**情境**：學生小明正在做「不同波長的光對葉片光合作用速率的影響」專案。

**系統原本（Before）**：LLM 看不到小明的實際進度，學生問「我下一步該做什麼？」——LLM 只能泛談擇策階段要做什麼，會建議他「列出變因」「查閱文獻」。

**系統串接專案資料後（After）**：LLM 看到小明已繳交：
- 研究問題（4/10）
- 變因設定：操縱 = 光源波長，應變 = 單位時間產氧量（4/9）
- 文獻回顧：Smith 2019、Chen 2020、Lin 2021 共 3 篇（4/8）

看板有三張任務：預約實驗室、準備葉片樣本、校正 pH 計。想法牆有節點：葉綠素、光反應、氧氣量、實驗對照組、波長。

LLM 的 After 回覆（節錄）：

> 很棒，我看到你已經交了文獻回顧（3 篇）和變因設定，研究問題也定好了——這代表你在擇策階段的「紙上作業」已完成 70%。
>
> 但看板「進行中」還是空的，也沒有操作型定義或預實驗計畫。下一步建議：
>
> 1. **確認操作型定義**：你寫「單位時間產氧量」，是打算用什麼方法量？水位法？溶氧計？這個還沒在 Submit 看到。
> 2. **設計預實驗**：你看板有三張準備任務，但「跑紅光組」這類實作還沒上板——你要不要先把預實驗的步驟拆成卡片？
> 3. **想法牆**我看到你有「對照組」這個節點——你的控制組打算怎麼設？恆定白光、全黑、還是？
>
> 你覺得這三項裡哪一個最卡？我們先從那個聊起。

## 問題 3：整體風險與你的直覺

**3-1 你覺得這個工具最大的風險是什麼？**（可複選）

- [ ] 學生會養成「有問題就問 AI」的依賴，不自己想
- [ ] LLM 可能給出錯誤的科學知識（例如實驗設計錯誤）
- [ ] LLM 的建議太泛，學生實際用不到
