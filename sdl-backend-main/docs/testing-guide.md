# AI 顧問能力測試指南

**測試 Phase 1：AI 能否主動分析和給建議**

---

## 測試場景 1：評估專案進度

### 輸入
```
學生問：「對於我的看板卡片，有沒有遺漏的步驟？」
```

### 預期 AI 行為（v2.1）

#### ✅ 應該做到：
1. **分析看板資料**
   - 統計各欄位任務數量
   - 識別任務分布是否合理

2. **主動指出問題**
   - 例如：「進行中」有太多任務同時進行
   - 例如：某些任務缺少明確的完成標準

3. **提供具體建議**
   - 建議優先完成哪些任務
   - 建議如何拆分或合併任務

4. **引導下一步行動**
   - 「建議你優先...」
   - 「可以考慮...」

#### ❌ 不應該：
- 只羅列任務清單，不分析
- 說「根據資料，你有 X 個任務」然後結束
- 不給任何建議

---

## 測試場景 2：請求執行操作

### 輸入
```
學生問：「可以幫我新增一個『準備資料』的任務嗎？」
```

### 預期 AI 行為（v2.1）

#### ✅ 應該做到：
1. **清楚說明限制**
   - 「我無法直接執行操作」
   - 「但可以指導你如何操作」

2. **提供詳細步驟**
   - 步驟 1：點擊...
   - 步驟 2：填寫...
   - 步驟 3：確認...

3. **額外給建議**
   - 「建議將『準備資料』拆分成更小的任務...」
   - 「可以加上標籤方便分類...」

#### ❌ 不應該：
- 說「我已經幫你新增了」（Phase 1 還不能執行）
- 迴避問題，不給引導
- 只說「我不能操作」然後結束

---

## 測試場景 3：主動提供建議

### 輸入
```
學生問：「我的專案進度如何？」
```

### 預期 AI 行為（v2.1）

#### ✅ 應該做到：
1. **評估進度**
   - 完成率分析
   - 與預期時程對比
   - 識別風險

2. **給出評價**
   - 「進度正常 ✅」或「進度落後 ⚠️」
   - 說明原因

3. **提供行動建議**
   - 「建議優先完成...」
   - 「接下來可以...」
   - 「如果遇到問題，可以...」

#### ❌ 不應該：
- 只說「你有 X 個任務完成」
- 不給任何評價或建議
- 不提供下一步行動

---

## 快速測試腳本

### 手動測試（建議）

1. 登入系統，進入有資料的專案
2. 打開 AI 助手聊天
3. 依序測試以上 3 個場景
4. 檢查 AI 回答是否符合預期

### 預期改善

| 場景 | v1.0 舊版 | v2.1 新版 |
|------|----------|----------|
| 評估進度 | 只描述 | 描述 + 分析 + 建議 |
| 請求操作 | 迴避/困惑 | 說明限制 + 引導步驟 |
| 主動建議 | 不主動 | 主動提供建議 |

---

## 如果 AI 表現不符預期

### 檢查清單

1. **檢查 Prompt 是否正確載入**
   ```bash
   # 檢查 assistantPrompts.js 是否包含新版準則
   grep "主動提供建議" sdl-backend-main/config/assistantPrompts.js
   # 應該看到第 89 行的內容
   ```

2. **檢查快取是否清除**
   - 舊的 projectContext 可能還在快取中
   - 重啟服務或等待 5 分鐘 TTL 過期

3. **檢查 AI 模型**
   ```javascript
   // controllers/assistant.js
   const model = 'gemini-2.5-flash';  // 確認使用的模型
   ```

4. **查看 AI 的 thinking 內容**
   - AI 的思考過程應該包含「分析」和「建議」
   - 如果沒有，可能是 Prompt 沒有生效

## 回滾方案（如果有問題）

如果新版 AI 表現不如預期，可以回滾：

```bash
# 恢復到 v1.0
git checkout HEAD~1 sdl-backend-main/config/assistantPrompts.js
git checkout HEAD~1 sdl-backend-main/config/promptBuilder.js

# 重啟服務
# （服務重啟命令根據部署方式而定）
```

或手動移除新增的準則 4 和 5。

## 長期觀察指標

部署後觀察這些指標：

1. **使用者滿意度**
   - 學生是否覺得 AI 更有幫助？
   - 提問頻率是否增加？

2. **Token 消耗**
   - 平均每次對話的 Token 數
   - 預期增加 5-10%

3. **對話長度**
   - 平均回覆字數
   - 預期從 ~50 字增加到 ~150 字

4. **錯誤率**
   - AI 是否給出不合理的建議？
   - 是否有誤導學生的情況？

---

**測試完成後**，如果效果良好，可以考慮進入 Phase 2（Function Calling）。
