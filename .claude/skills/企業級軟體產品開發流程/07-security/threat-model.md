# Threat Model 威脅建模

## 概述

此 skill 提供威脅建模指引，系統性識別、評估安全威脅，並制定緩解措施。

## 適用角色

| 角色 | 職責 |
|------|------|
| **主要負責** | 安全工程師 |
| **協作角色** | 架構師、開發工程師 |

---

## 1. STRIDE 威脅分類

| 類型 | 威脅 | 說明 |
|------|------|------|
| **S** | Spoofing | 身份偽造 |
| **T** | Tampering | 資料竄改 |
| **R** | Repudiation | 否認行為 |
| **I** | Information Disclosure | 資訊洩露 |
| **D** | Denial of Service | 阻斷服務 |
| **E** | Elevation of Privilege | 權限提升 |

---

## 2. 威脅建模流程

```
1. 定義範圍 → 2. 繪製資料流圖 → 3. 識別威脅 → 4. 評估風險 → 5. 制定緩解
```

### 2.1 資料流圖 (DFD)

```
┌─────────┐     HTTPS      ┌─────────────┐
│  User   │ ─────────────→ │  Web App    │
└─────────┘                └─────────────┘
                                 │ JWT
                                 ▼
                           ┌─────────────┐     SQL      ┌──────────┐
                           │  API Server │ ──────────→ │ Database │
                           └─────────────┘              └──────────┘
```

### 2.2 信任邊界

| 邊界 | 描述 |
|------|------|
| TB-1 | 用戶設備 → Web 應用 |
| TB-2 | Web 應用 → API Server |
| TB-3 | API Server → Database |

---

## 3. 威脅識別表

| ID | 資產 | 威脅類型 | 威脅描述 | 嚴重度 |
|----|------|---------|---------|--------|
| T-001 | 用戶帳號 | Spoofing | 攻擊者竊取 Session | 高 |
| T-002 | 用戶資料 | Info Disclosure | SQL Injection 洩露 | 嚴重 |
| T-003 | API Server | DoS | 暴力攻擊癱瘓服務 | 中 |
| T-004 | 訂單資料 | Tampering | 竄改訂單金額 | 高 |
| T-005 | 管理功能 | Elevation | 普通用戶存取後台 | 嚴重 |

---

## 4. 風險評估

### DREAD 評分

| 因素 | 說明 | 權重 |
|------|------|------|
| **D**amage | 損害程度 | 1-10 |
| **R**eproducibility | 可重現性 | 1-10 |
| **E**xploitability | 可利用性 | 1-10 |
| **A**ffected Users | 影響用戶數 | 1-10 |
| **D**iscoverability | 可發現性 | 1-10 |

**風險 = (D + R + E + A + D) / 5**

| 分數 | 風險等級 |
|------|---------|
| 8-10 | 🔴 嚴重 |
| 5-7 | 🟠 高 |
| 3-4 | 🟡 中 |
| 1-2 | 🟢 低 |

---

## 5. 緩解措施

| 威脅 ID | 緩解措施 | 優先級 |
|---------|---------|--------|
| T-001 | HttpOnly Cookie + CSRF Token | P0 |
| T-002 | 參數化查詢 + ORM | P0 |
| T-003 | Rate Limiting + WAF | P1 |
| T-004 | 伺服器端驗證 + 簽章 | P0 |
| T-005 | RBAC + 權限檢查中介軟體 | P0 |
