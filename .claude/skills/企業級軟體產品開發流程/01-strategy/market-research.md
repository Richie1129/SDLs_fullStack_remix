# 市場研究分析

## 概述
此 skill 協助進行全面的市場研究分析，包括市場規模評估 (TAM/SAM/SOM)、競爭對手分析、目標用戶研究和趨勢分析。適用於新產品開發的策略規劃階段，為商業決策提供數據支持。

## 適用角色
- **主要負責**: 市場研究分析師、產品策略師、商業分析師
- **協作角色**: 產品經理、高階主管、業務團隊

## 輸入需求
使用者需要提供：
- 產品或服務概念描述
- 目標市場或產業領域
- 主要競爭對手（如已知）
- 研究目的和關鍵問題

範例：`請幫我進行市場研究分析，產品是 [產品描述]，目標市場是 [市場描述]`

## 執行步驟

### 步驟 1: 定義研究範圍
- 明確產品/服務定位
- 確認目標市場地理範圍
- 識別研究的關鍵問題
- 設定研究時程和資源

### 步驟 2: 市場規模分析
- 計算 TAM (Total Addressable Market) - 總潛在市場
- 計算 SAM (Serviceable Addressable Market) - 可服務市場
- 計算 SOM (Serviceable Obtainable Market) - 可獲取市場
- 分析市場成長趨勢

### 步驟 3: 競爭對手分析
- 識別直接和間接競爭者
- 建立競爭對手檔案（產品、定價、市場份額）
- 進行 SWOT 分析
- 建立競品功能矩陣

### 步驟 4: 目標用戶研究
- 設計用戶訪談或問卷
- 建立用戶畫像 (Persona)
- 繪製用戶旅程地圖
- 識別用戶痛點和需求

### 步驟 5: 趨勢分析
- 分析產業技術趨勢
- 研究市場發展趨勢
- 檢視相關法規和政策變化
- 評估機會和威脅

### 步驟 6: 綜合報告
- 彙整研究發現
- 提出策略建議
- 識別關鍵成功因素
- 標示風險和假設

## 1. 市場規模分析

### 1.1 TAM (Total Addressable Market) - 總潛在市場

**定義**: [說明如何定義這個市場]

**市場規模**:
- **全球市場**: $X 億美元 (YYYY 年)
- **目標區域市場**: $X 億美元
- **預期成長率**: X% CAGR (YYYY-YYYY)

**計算方法**:
```
TAM = [目標用戶總數] × [年平均消費金額]
TAM = [具體數字] × [具體金額] = $X 億美元
```

**資料來源**: [市場研究報告、政府統計、產業報告等]

### 1.2 SAM (Serviceable Addressable Market) - 可服務市場

**定義**: [基於產品特性和銷售管道可觸及的市場]

**市場規模**: $X 億美元

**計算方法**:
```
SAM = TAM × [地理覆蓋率] × [產品適配度]
SAM = $X 億 × X% × X% = $X 億美元
```

**篩選條件**:
- 地理範圍: [列出涵蓋的國家/地區]
- 客戶類型: [B2B/B2C/特定產業]
- 產品適配: [符合我們產品定位的市場區塊]

### 1.3 SOM (Serviceable Obtainable Market) - 可獲取市場

**市場規模**: $X 億美元

**計算方法**:
```

```

## 範例

### 輸入範例
```
請幫我進行市場研究分析，產品是一個針對中小企業的智慧客服 SaaS 平台，
目標市場是台灣和東南亞，主要競爭對手包括 Zendesk、Intercom 和本地廠商。
```

### 輸出範例
[生成完整的市場研究報告，包含：]
- TAM: 亞太區智慧客服市場 $15 億美元
- SAM: 台灣+東南亞中小企業市場 $2.5 億美元  
- SOM: 3 年內可獲取 $25 百萬美元（1% 市場佔有率）
- 競爭分析: Zendesk (功能完整但昂貴), Intercom (強在行銷自動化)
- 用戶畫像: "忙碌的客服主管 Amy" - 需要自動化但預算有限
- 關鍵機會: 中文語系優勢 + 中小企業友善定價
- 建議: 先攻台灣市場，再擴展東南亞
