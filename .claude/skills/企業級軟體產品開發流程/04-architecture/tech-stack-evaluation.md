# 技術堆疊評估 (Tech Stack Evaluation)

## 概述
此 skill 協助評估和選擇適合專案的技術堆疊，系統性分析各技術選項的優缺點、適用場景、成本和風險，確保技術決策符合業務需求和團隊能力。

## 適用角色
- **主要負責**: 技術主管、系統架構師、資深工程師
- **協作角色**: 產品經理、開發團隊、DevOps 工程師

## 輸入需求
使用者需要提供：
- 專案需求和目標
- 團隊技能和經驗
- 時程和預算限制
- 效能和擴展需求
- 現有技術生態系統

範例：`請幫我評估前端框架選擇，我們在考慮 React vs Vue vs Angular`

## 執行步驟

### 步驟 1: 需求釐清
- 定義評估範圍
- 識別關鍵需求
- 確定評估標準

### 步驟 2: 候選技術調研
- 收集候選技術
- 了解各技術特性
- 研究生態系統

### 步驟 3: 建立評估框架
- 定義評估維度
- 設定權重
- 建立評分標準

### 步驟 4: 進行評估
- 逐項評分
- 進行 PoC（如需要）
- 收集團隊回饋

### 步驟 5: 做出建議
- 綜合分析結果
- 提出建議方案
- 說明風險和緩解措施
