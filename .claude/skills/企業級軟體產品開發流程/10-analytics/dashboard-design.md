# Dashboard Design 儀表板設計

## 概述

此 skill 提供數據儀表板設計指引，有效展示關鍵指標。

## 適用角色

| 角色 | 職責 |
|------|------|
| **主要負責** | 數據分析師、產品經理 |
| **使用者** | 管理層、各團隊 |

---

## 1. 設計原則

- **目標導向**: 回答特定問題
- **簡潔清晰**: 避免資訊過載
- **可操作**: 能引導決策
- **即時更新**: 數據新鮮度

---

## 2. 儀表板類型

| 類型 | 受眾 | 更新頻率 | 內容 |
|------|------|---------|------|
| **戰略型** | 管理層 | 每日/週 | 高階 KPI |
| **營運型** | 營運團隊 | 即時/小時 | 營運指標 |
| **分析型** | 分析師 | 隨需 | 深度分析 |

---

## 3. 佈局設計

### 金字塔結構

```
┌─────────────────────────────────────────┐
│           核心 KPI (最重要)              │ ← 頂部
├─────────────────────────────────────────┤
│     趨勢圖表    │     分布圖表          │ ← 中部
├─────────────────────────────────────────┤
│   維度分析    │   比較表格   │  明細    │ ← 底部
└─────────────────────────────────────────┘
```

### 範例佈局

```
┌────────┬────────┬────────┬────────┐
│  DAU   │  收入   │ 轉換率  │ 留存率  │  ← 核心指標卡
├────────┴────────┴────────┴────────┤
│                                    │
│       DAU 趨勢 (折線圖)             │  ← 趨勢圖表
│                                    │
├─────────────────┬──────────────────┤
│   來源分布      │    平台分布       │  ← 分布圖表
│   (圓餅圖)      │    (長條圖)       │
├─────────────────┴──────────────────┤
│                                    │
│        Top 10 商品 (表格)           │  ← 排行表格
│                                    │
└────────────────────────────────────┘
```

---

## 4. 圖表選擇

| 用途 | 推薦圖表 |
|------|---------|
| 趨勢變化 | 折線圖、面積圖 |
| 佔比分布 | 圓餅圖、環形圖 |
| 比較數值 | 長條圖、柱狀圖 |
| 相關性 | 散點圖 |
| 地理分布 | 地圖 |
| 流程漏斗 | 漏斗圖 |

---

## 5. 設計規範

### 顏色使用

```
主要指標: 品牌藍 #2563EB
正向趨勢: 綠色 #10B981
負向趨勢: 紅色 #EF4444
中性/背景: 灰色 #6B7280
```

### 數字格式

| 類型 | 格式 | 範例 |
|------|------|------|
| 大數字 | 縮寫 | 1.2M、45K |
| 金額 | 千分位 | $1,234,567 |
| 百分比 | 1 位小數 | 23.5% |
| 變化 | 帶符號 | +12.3%、-5.2% |

---

## 6. 互動設計

- **篩選器**: 日期、分類、地區
- **下鑽**: 點擊查看明細
- **懸停**: 顯示詳細數值
- **導出**: CSV、PDF

---

## 7. 儀表板文件

```markdown
# 儀表板規格

## 基本資訊
- **名稱**: 每日營運儀表板
- **目標受眾**: 營運團隊
- **更新頻率**: 每小時

## 回答問題
1. 今日業績如何？
2. 哪個管道表現最好？
3. 有異常需要處理嗎？

## 指標清單
| 指標 | 計算方式 | 目標 |
|------|---------|------|
| DAU | ... | 50K |
| 收入 | ... | $100K |

## 篩選器
- 日期範圍
- 平台
- 地區
```
