# 產品需求文件 (PRD)

## 概述
此 skill 協助撰寫完整的產品需求文件，包含產品目標、功能規格、使用者流程、優先級和成功指標。

## 適用角色
- **主要負責**: 產品經理
- **協作角色**: 技術主管、設計師、業務團隊、QA

## 輸入需求
- 產品探索結果
- 用戶故事集合
- 商業目標
- 技術限制

範例：`請幫我撰寫 [產品名稱] 的 PRD`

## 執行步驟

### 步驟 1: 定義產品目標和範圍
### 步驟 2: 描述功能需求
### 步驟 3: 定義成功指標
### 步驟 4: 規劃發布計畫
### 步驟 5: 審核和簽核
