# 線框圖規劃

## 概述
此 skill 協助建立線框圖 (Wireframe)，從低保真到高保真，規劃頁面佈局、元素配置和互動流程。

## 適用角色
- **主要負責**: UX 設計師
- **協作角色**: 產品經理、UI 設計師

## 輸入需求
- 資訊架構
- 用戶流程圖
- 功能需求

## 執行步驟

### 步驟 1: 低保真草圖
### 步驟 2: 中保真線框圖
### 步驟 3: 高保真線框圖
### 步驟 4: 互動原型
### 步驟 5: 用戶測試

## 輸出模板

```markdown
# 線框圖文件

## 頁面: 首頁

### 低保真線框圖

```
┌─────────────────────────────┐
│  [Logo]      Nav  Nav  [CTA] │
├─────────────────────────────┤
│                             │
│     [Hero Image]            │
│                             │
│  主標題                      │
│  副標題                      │
│  [CTA Button]               │
│                             │
├─────────────────────────────┤
│  功能 1  │ 功能 2  │ 功能 3  │
├─────────────────────────────┤
│     客戶見證區塊             │
├─────────────────────────────┤
│        [Footer]             │
└─────────────────────────────┘
```

### 元件說明

**Header (導航列)**
- Logo: 左上角，可點擊回首頁
- 主導航: 水平排列
- CTA 按鈕: 「免費試用」

**Hero Section**
- 大標題: 40px
- 副標題: 20px
- 主要 CTA: 醒目按鈕
- 背景: Hero 圖片或插圖

**功能展示**
- 3 欄式佈局
- 圖示 + 標題 + 說明

### 響應式設計

**Desktop (≥1024px)**
- 3 欄佈局
- 完整導航

**Tablet (768-1023px)**
- 2 欄佈局
- 簡化導航

**Mobile (<768px)**
- 單欄佈局
- 漢堡選單
```
