# 策略審批文件

## 概述
此 skill 協助準備完整的策略審批文件和簡報，用於向高階主管或董事會爭取專案或策略的核准。包含執行摘要、策略簡報、預算申請和資源配置規劃。

## 適用角色
- **主要負責**: 產品副總、策略規劃師、專案發起人
- **協作角色**: 產品經理、財務長、執行長

## 輸入需求
使用者需要提供：
- 完整的商業論證文件
- 審批對象（董事會/管理層/投資委員會）
- 審批會議時間和格式
- 關鍵決策者關注點

範例：`請幫我準備 [專案名稱] 的策略審批文件，將在 [日期] 向 [審批對象] 簡報`

## 執行步驟

### 步驟 1: 了解決策者需求
- 確認決策者是誰
- 了解他們的關注重點
- 識別潛在反對意見
- 確認審批標準

### 步驟 2: 準備執行摘要
- 濃縮商業論證精華
- 突出關鍵數字和效益
- 明確說明需要的決策
- 限制在 1-2 頁

### 步驟 3: 製作策略簡報
- 設計清晰的故事線
- 準備視覺化圖表
- 預估簡報時間（通常 15-30 分鐘）
- 準備 Q&A

### 步驟 4: 準備支持文件
- 詳細財務模型
- 風險分析報告
- 市場研究數據
- 技術可行性評估

### 步驟 5: 利害關係人預溝通
- 與關鍵決策者個別溝通
- 收集回饋並調整
- 爭取支持者
- 化解反對意見

### 步驟 6: 排練和優化
- 進行簡報排練
- 預測可能問題並準備答案
- 優化簡報流程
- 準備備用方案

## 📝 Q&A 準備

### 預期問題與答案

#### 財務相關

**Q1: 如果收益不如預期怎麼辦？**
**A**: 我們做了敏感度分析。即使收益下降 20%，ROI 仍有 XX%，專案仍然可行。此外，我們規劃了分階段實施，可以在早期發現問題並調整。

**Q2: 為何需要這麼多預算？**
