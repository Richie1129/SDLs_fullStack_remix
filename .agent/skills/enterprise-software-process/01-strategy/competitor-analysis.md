# 競爭對手分析

## 概述
此 skill 協助進行深入的競爭對手分析，包括競爭對手的產品、策略、優勢劣勢分析，並建立競爭定位策略。適用於需要了解競爭環境並制定差異化策略的情境。

## 適用角色
- **主要負責**: 產品經理、市場分析師、產品策略師
- **協作角色**: 業務團隊、行銷團隊、技術主管

## 輸入需求
使用者需要提供：
- 主要競爭對手名單（3-10 個）
- 分析重點領域（產品功能、定價、市場策略等）
- 分析目的（例如：找出差異化機會、定價策略等）

範例：`請幫我分析 [競爭對手列表]，重點關注 [功能/定價/市場策略]`

## 執行步驟

### 步驟 1: 識別競爭對手
- 列出直接競爭者（同類產品/服務）
- 列出間接競爭者（替代方案）
- 識別潛在競爭者（新進入者）
- 按威脅程度排序

### 步驟 2: 收集競爭情報
- 分析競爭對手官網和產品文件
- 研究競爭對手的行銷材料
- 分析客戶評價和社群反饋
- 追蹤競爭對手的新聞和公告
- 試用競爭對手產品（如可行）

### 步驟 3: 多維度分析
- 產品功能比較
- 定價策略分析
- 目標市場定位
- 技術架構評估
- 使用者體驗比較
- 市場行銷策略
- 客戶服務水準

### 步驟 4: SWOT 分析
- 為每個競爭對手進行 SWOT 分析
- 識別我們相對於競爭對手的優勢
- 找出可以利用的競爭對手弱點

### 步驟 5: 制定競爭策略
- 找出差異化機會
- 制定定位策略
- 規劃競爭應對措施
- 設定競爭監控機制
