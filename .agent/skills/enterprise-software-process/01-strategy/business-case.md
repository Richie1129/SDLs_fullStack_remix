# 商業論證 (Business Case)

## 概述
此 skill 協助撰寫完整的商業論證文件，包括價值主張、財務模型、成本效益分析、風險評估和投資建議。用於說服決策者核准專案或產品投資。

## 適用角色
- **主要負責**: 產品經理、商業分析師、財務分析師
- **協作角色**: 策略規劃師、財務長、產品副總

## 輸入需求
使用者需要提供：
- 專案或產品概述
- 預期目標和效益
- 初步成本估算
- 時程規劃
- 關鍵假設

範例：`請幫我撰寫 [專案名稱] 的商業論證，預期效益是 [說明]，預估成本 [金額]`

## 執行步驟

### 步驟 1: 定義問題和機會
- 明確陳述要解決的問題
- 量化問題的影響
- 描述商業機會
- 說明不採取行動的後果

### 步驟 2: 提出解決方案
- 描述建議的解決方案
- 說明方案如何解決問題
- 列出關鍵功能和能力
- 定義成功標準

### 步驟 3: 財務分析
- 估算開發成本（一次性）
- 估算營運成本（持續性）
- 預測收入或成本節省
- 計算 ROI、NPV、回本期

### 步驟 4: 風險評估
- 識別主要風險
- 評估風險機率和影響
- 提出風險緩解策略
- 建立應變計畫

### 步驟 5: 比較替代方案
- 列出其他可能方案
- 比較各方案優缺點
- 說明為何選擇建議方案

### 步驟 6: 制定實施計畫
- 定義里程碑和時程
- 規劃資源需求
- 設定治理結構
- 建立監控機制
