# AI 助手能力升級：從「查詢機器人」到「專案顧問」

**日期**: 2025-01-11
**目的**: 讓 AI 能分析問題並給建議，不只是回答問題
**設計哲學**: Linus - "解決實際問題，而不是假想的威脅"

---

## 問題診斷

### 使用者的實際需求

**學生的真實提問**：
1. ❓ 「對於我的看板卡片，有沒有遺漏的步驟？」
2. ❓ 「可以幫我新增任務嗎？」
3. ❓ 「我的專案進度落後了嗎？接下來該做什麼？」

### 原始系統的限制

#### ❌ **限制 1：只能「描述」，不能「分析」**

**原始對話**：
```
學生：「對於我的看板，有沒有遺漏的步驟？」

AI（原始 v1.0）：
「你的看板中有 3 個欄位：
- 待辦：5 個任務
- 進行中：3 個任務
- 完成：2 個任務」

❌ 只描述現狀，沒有分析問題
```

**根本原因**：
```javascript
// assistantPrompts.js v1.0
const ASSISTANT_ROLE = '你是一個專案助理 AI，專門協助使用者了解和管理他們的學習專案。';
// ❌ 只說「了解和管理」，沒有明確「分析和建議」
```

---

#### ❌ **限制 2：不敢給建議，怕「編造資訊」**

**原始對話**：
```
學生：「我的專案進度如何？」

AI（原始 v1.0）：
「你有 10 個任務，其中 5 個在進行中...」

❌ 不敢評估「進度是快還是慢」
❌ 不敢建議「應該優先做什麼」
```

**根本原因**：
```javascript
// getAnswerGuidelines v1.0
準則 2: 根據實際專案資料回答，不要編造不存在的資訊
// ❌ AI 誤解為「不能給建議」
```

---

#### ❌ **限制 3：不知道自己「不能執行操作」**

**原始對話**：
```
學生：「可以幫我新增一個任務嗎？」

AI（原始 v1.0）：
「[困惑] 根據你的專案資料...」

❌ 不知道該回答什麼
❌ 沒有引導學生如何操作
```

**根本原因**：
- Prompt 沒有告訴 AI「你不能執行操作」
- 沒有教 AI「如何引導學生手動操作」

**2. 實作工具執行函數**

```javascript
// controllers/assistantActions.js
async function executeCreateTask(args, projectId, userId) {
  const { title, content, columnName, assignee } = args;

  // 1. 找到目標欄位
  const column = await Column.findOne({
    where: { name: columnName, projectId }
  });

  if (!column) {
    throw new Error(`找不到欄位「${columnName}」`);
  }

  // 2. 創建任務
  const task = await Task.create({
    title,
    content: content || '',
    columnId: column.id,
    owner: assignee || userId,
    assignees: assignee ? [{ username: assignee }] : []
  });

  // 3. 更新欄位
  column.task = [...column.task, task.id];
  await column.save();

  // 4. 記錄日誌
  await logTaskChange({
    taskId: task.id,
    changeType: 'create',
    changedBy: 'AI 助手',
    projectId,
    description: `AI 助手建立任務「${title}」`
  });

  // 5. 清除快取
  invalidateProjectCache(projectId);

  // 6. 廣播事件（讓前端即時更新）
  io.to(`project-${projectId}`).emit('taskItemCreated', {
    taskId: task.id,
    columnId: column.id,
    projectId
  });

  return {
    success: true,
    taskId: task.id,
    message: `已成功建立任務「${title}」在「${columnName}」欄位`
  };
}
```

**3. 整合 Function Calling 流程**

```javascript
// controllers/assistant.js - chat endpoint
exports.chat = async (req, res) => {
  // ... 原有邏輯 ...

  // 初始化 Gemini 模型（啟用 Function Calling）
  const model = genAI.getGenerativeModel({
    model: 'gemini-3.1-flash-lite-preview',
    tools: tools  // 傳入工具定義
  });

  // 建立對話
  const chat = model.startChat({
    history: chatHistory,
    systemInstruction: promptBuilder.forGemini(message)
  });

  // 發送訊息
  let result = await chat.sendMessage(message);
  let response = result.response;

  // 檢查是否有 Function Call
  if (response.functionCalls) {
    console.log('🔧 AI 請求執行工具:', response.functionCalls);

    // 執行所有 Function Calls
    const functionResults = await Promise.all(
      response.functionCalls.map(async (call) => {
        try {
          let result;

          switch (call.name) {
            case 'createTask':
              result = await executeCreateTask(call.args, projectId, userId);
              break;
            case 'updateTask':
              result = await executeUpdateTask(call.args, projectId, userId);
              break;
            // ... 其他工具
            default:
              throw new Error(`未知的工具: ${call.name}`);
          }

          return {
            functionResponse: {
              name: call.name,
              response: result
            }
          };
        } catch (error) {
          return {
            functionResponse: {
              name: call.name,
              response: {
                success: false,
                error: error.message
              }
            }
          };
        }
      })
    );

    // 將執行結果回傳給 AI，讓它生成自然語言回覆
    result = await chat.sendMessage(functionResults);
    response = result.response;
  }

  // Stream 回覆給前端
  const finalResponse = response.text();
  res.write(finalResponse);
  res.end();
};
```

### Phase 2 設計考量

#### ✅ **優點**

1. **真正的 AI 助手**：不只建議，能真的幫忙做事
2. **自然語言操作**：「幫我新增任務」比手動點擊更快
3. **減少學習成本**：不需要學 UI 操作，直接用對話完成

#### ⚠️ **挑戰**

1. **安全性**：
   - AI 可能誤解指令（例如刪錯任務）
   - 需要權限檢查：AI 只能操作使用者有權限的資料
   - 需要確認機制：「你確定要刪除 5 個任務嗎？」

2. **複雜度**：
   - Function Calling 增加系統複雜度
   - 錯誤處理更困難
   - 需要更多測試

3. **使用者體驗**：
   - 操作失敗時的回饋
   - 操作成功後的視覺更新（需要前端配合）

#### 🛡️ **安全措施**

```javascript
// 權限檢查
async function executeCreateTask(args, projectId, userId) {
  // 1. 檢查使用者權限
  const hasPermission = await checkProjectWritePermission(projectId, userId);
  if (!hasPermission) {
    throw new Error('你沒有權限在此專案新增任務');
  }

  // 2. 驗證參數
  if (!args.title || args.title.trim().length === 0) {
    throw new Error('任務標題不能為空');
  }

  // 3. 限制批量操作
  const MAX_TASKS_PER_REQUEST = 10;
  if (args.tasks && args.tasks.length > MAX_TASKS_PER_REQUEST) {
    throw new Error(`一次最多只能建立 ${MAX_TASKS_PER_REQUEST} 個任務`);
  }

  // 4. 記錄所有操作（審計日誌）
  await AuditLog.create({
    userId,
    projectId,
    action: 'AI_CREATE_TASK',
    details: JSON.stringify(args),
    timestamp: new Date()
  });

  // ... 執行操作 ...
}
```

## 常見問題 (FAQ)

### Q1: Phase 1 會讓 AI 回答變長嗎？

**A**: 可能會，但這是**預期行為**
- 舊版：只描述現狀（~50 字）
- 新版：描述 + 分析 + 建議（~150-200 字）
- 權衡：資訊價值 >> 文字長度

如果覺得太長，可以調整 Prompt：
```javascript
準則 4: 主動提供建議（簡明扼要，控制在 3 條建議內）
```

### Q2: Phase 1 會增加 Token 消耗嗎？

**A**: 會，但增加幅度小
- Prompt 增加：~100 tokens（角色定義 + 準則）
- AI 回覆增加：~50-100 tokens（建議內容）
- 總增幅：~5-10%

權衡：使用者滿意度 >> Token 成本
